## Instalación

<Tabs items={['macOS', 'Windows', 'Linux']}>
<Tab value="macOS">

### Apple Silicon (M1 / M2 / M3 / M4)

1. Descarga `tpv-haido-0.1.0-macos-arm64.dmg` con el botón de arriba.
2. Abre el `.dmg` haciendo doble clic.
3. Arrastra `TPV El Haido.app` a la carpeta `Applications`.
4. La primera vez: clic derecho sobre la app → **Abrir** (esto es para saltarse Gatekeeper, ya que la firma es propia, no de Apple).

```bash title="Verificar checksum (opcional)"
# El binario está firmado con minisign. La verificación la hace
# automáticamente Tauri al recibir actualizaciones.
shasum -a 256 ~/Downloads/tpv-haido-0.1.0-macos-arm64.dmg
```

<Callout type="info">
  A partir de la primera versión, las actualizaciones llegan solas sin descargar nada manualmente. La app comprueba `https://haido.releases.mks2508.systems/api/updates/...` al iniciar.
</Callout>

</Tab>

## Auto-actualización

TPV El Haido usa el sistema de actualizaciones nativo de Tauri:

1. Al arrancar, la app pregunta a `haido.releases.mks2508.systems` si hay versión nueva.
2. Si la hay, se descarga el bundle firmado en background.
3. Una notificación te pide reiniciar para aplicar la actualización.
4. La firma minisign garantiza que el binario no ha sido alterado durante la descarga.

No hace falta reinstalar manualmente nunca más después de la primera vez.
