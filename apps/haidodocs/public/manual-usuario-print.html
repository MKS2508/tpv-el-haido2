Introducción

Bienvenido a TPV El Haido, tu sistema de punto de venta diseñado específicamente para hostelería. Esta guía te acompañará desde la instalación hasta el dominio completo de todas las funcionalidades.

1.1 ¿Qué puedes hacer con TPV El Haido?

Funcionalidad Descripción
Pedidos Crea comandas, gestiona mesas y cobra de forma rápida
Productos Organiza tu catálogo con categorías, precios e imágenes
Clientes Mantén una base de datos para facturas completas
Pagos Efectivo, tarjeta o mixto con cálculo automático de cambio
Impresión Tickets térmicos personalizados con tu logo
Facturación Envío automático a la AEAT con VERI*FACTU

1.2 Flujo de trabajo típico

El uso diario de TPV El Haido sigue este flujo sencillo:

💡 Consejo: Para empezar rápidamente, completa el asistente de configuración inicial y crea tu primer producto en menos de 5 minutos.
2

Instalación

2.1 Requisitos del sistema

Componente Mínimo Recomendado
RAM 512 MB 1 GB o más
Almacenamiento 100 MB 500 MB
Pantalla 800×600 1024×768 o superior
Internet Opcional Requerido para VERI*FACTU

2.2 Instalación en Windows 10/11

  1. Accede a GitHub Releases
  2. Descarga el archivo TPV.El.Haido_x.x.x_x64-setup.exe
  3. Haz doble clic en el archivo descargado
  4. Si aparece Windows SmartScreen, haz clic en "Más información" y luego "Ejecutar de todas formas"
  5. Sigue el asistente de instalación
  6. Busca "TPV El Haido" en el menú de inicio
⚠️ Windows SmartScreen: Al ser una aplicación no firmada por Microsoft, Windows puede mostrar una advertencia. Esto es completamente normal para software independiente.
3

Primeros Pasos

3.1 Pantalla de login

Después de la configuración, verás la pantalla de acceso:

Para acceder:

  1. Toca tu avatar para seleccionar tu usuario
  2. Introduce tu PIN de 4 dígitos
  3. Pulsa Enter o el botón de acceso

3.2 Realizar tu primera venta

Paso 1: En el menú lateral, haz clic en Nueva Comanda

Paso 2: Añade productos tocando las categorías y seleccionando los productos

Paso 3: Haz clic en Cobrar, selecciona el método de pago y confirma

El ticket se imprimirá automáticamente si tienes una impresora configurada.

4

Gestión de Pedidos

4.1 Crear una nueva comanda

El proceso es simple:

  1. Selecciona una mesa (o "Barra" / "Para llevar")
  2. Navega por las categorías en la barra lateral
  3. Haz clic en los productos para añadirlos
  4. Revisa el resumen en el panel derecho
  5. Haz clic en "Cobrar" cuando estés listo

5

Gestión de Productos

5.1 Crear un producto

  1. Ve a Productos en el menú lateral
  2. Haz clic en Nuevo Producto
  3. Rellena la información:
Campo Ejemplo Obligatorio
Nombre Cerveza Sí
Precio 2.50 Sí
Categoría Bebidas Sí
IVA 21% Sí

Precio sin IVA: Introduce siempre el precio sin IVA. El sistema calcula el PVP automáticamente.

6

Gestión de Clientes

6.1 Crear un nuevo cliente

  1. En el menú lateral, haz clic en Clientes
  2. Haz clic en Nuevo Cliente
  3. Completa los datos básicos:
  • Nombre: Nombre completo o razón social
  • NIF/CIF: Identificación fiscal
  • Email: Correo electrónico
  • Teléfono: Número de contacto
💡 Facturación: Para generar facturas completas (F1), el cliente debe tener NIF y dirección fiscal completa.

7.2 Pago mixto

Para combinar varios métodos de pago:

  1. En la pantalla de cobro, haz clic en Pago Mixto
  2. Selecciona el primer método (ej: Tarjeta) e introduce el importe parcial
  3. Haz clic en Añadir
  4. El resto aparece pendiente
  5. Selecciona otro método y completa
  6. Confirma cuando la suma cubra el total
8

Facturación VERI*FACTU

TPV El Haido incluye integración con el sistema VERI*FACTU de la Agencia Tributaria.

8.1 Configuración inicial

Pasos para configurar:

  1. Ve a Ajustes → VERI*FACTU
  2. Introduce los datos del emisor (NIF, Razón Social, Dirección)
  3. Configura la serie de factura (prefijo y número inicial)
  4. Selecciona el tipo de factura (F1 completa o F2 simplificada)
  5. Carga tu certificado digital (PFX/P12)
  6. Selecciona el entorno (Pruebas o Producción)
⚠️ Importante: Asegúrate de estar en modo Producción cuando operes de forma real. Las facturas en modo Pruebas no son válidas fiscalmente.
9

Configuración de Impresora

9.1 Impresoras compatibles

TPV El Haido soporta cualquier impresora compatible con el protocolo ESC/POS:

Marca Modelos probados
Epson TM-T20, TM-T88, TM-T82
Star TSP100, TSP650, mPOP
Bixolon SRP-330, SRP-350

9.2 Personalizar tickets

En Ajustes → Impresora → Ticket puedes configurar:

  • Logo: Imagen en la cabecera (BMP monocromo)
  • Nombre negocio: Se muestra en grande en la cabecera
  • Dirección: Línea de dirección
  • CIF/NIF: Identificación fiscal
  • Teléfono: Número de contacto
  • Mensaje pie: Texto personalizado al final
