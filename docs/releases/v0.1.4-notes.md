## ✨ Cambios principales

Hemos introducido el nuevo **Asistente de Instalación** (TR-19) para TPV El Haido, facilitando
la configuración inicial y el despliegue. Adicionalmente, migramos llamadas internas de
storage y auditoría a `PlatformService` (R1, R2), lo que facilita futuras compatibilidades
multi-plataforma.

## 🏗️ Arquitectura

La migración a `PlatformService` (R1, R2) consolida 27 invocaciones de storage y auditoría,
aislando las operaciones de plataforma. El nuevo sidecar instalador Rust gestiona la
instalación/rollback e integración con `release-hub` (TR-19.B). `isTauri()` se estandarizó para
Tauri 2.x en `http-storage-adapter` (`50b3d23`).
